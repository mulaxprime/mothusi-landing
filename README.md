# Mothusi Landing Page

The official landing page for **Mothusi** — an AI-powered study assistant built for BGCSE Computer Studies students in Form 4 and 5.

## About Mothusi

Mothusi is a voice-and-text AI study companion, built solo by [Amantle "Mulax Prime" Mpaekae](https://github.com/mulaxprime), tailored specifically to the BGCSE Computer Studies syllabus.

It's currently at **V3.1**, with features including:

- Groq-powered AI responses scoped to the syllabus
- Voice input and text-to-speech
- Quiz mode with scoring and review
- Session auto-save

## This Repository

This repository contains the standalone marketing and landing page for Mothusi.

It is also part of my self-directed web development learning journey, where I document my progress while building practical projects and learning new technologies.

The main landing page includes:

- `index.html` — page structure
- `css/style.css` — styling
